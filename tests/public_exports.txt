# Export name: one-line user task served by the root import.
# Keep this inventory in exact parity with increment.__all__; the check rejects
# both unjustified root names and entries for names no longer exported.
Analysis: Declare an experiment and its analysis inputs.
Definitions: Load experiment and metric definitions from YAML.
Metric: Select a metric definition from the supported metric types.
MetricSpec: Define a metric to estimate from a dataframe column.
CupedCovariate: Declare one covariate used by a CUPED method.
CupedCovariateBinding: Bind a CUPED covariate to a declared property or pre-period measure.
Winsorization: Bound a mean metric's outcomes before aggregation.
Design: Declare the experiment's assignment and identification design.
Randomized: Describe random assignment with a named control arm.
Observational: Define an adjusted non-randomized comparison.
Encouragement: Describe random encouragement assignment and participant uptake.
UptakeSpec: Declare the binary uptake fact for an encouragement study.
ExclusionRestriction: State the exclusion assumption for an encouragement effect.
AdjustmentSet: Name covariates used to adjust an observational comparison.
IdentificationGate: Set overlap and positivity rules for an observational comparison.
AnalysisPlan: Register the evidence and decision rule for an analysis.
MultiplicitySpec: Choose how a segmented family of results is multiplicity-adjusted.
ExperimentMetric: Assign a method, role, and prior to one experiment metric.
InferenceSpec: Select exact or explicitly asymptotic inference for an analysis.
Method: Choose an estimation method and its optional adjustments.
MethodSpec: Declare an estimation method and its CUPED inputs.
__version__: Check the installed package version.
EvidenceProvider: Implement typed statistical evidence for a custom data source.
RunResult: Return stored result cells, effects, and final decision verdicts from an analysis run.
run: Register an analysis before execution, persist its result cells, then decide from the validated run.
Experiment: Describe an immutable analysis, its evidence references, and its selected scopes.
SourceReference: Record a named evidence source, its expected digest, schema, and capabilities.
Resolver: Bind declared evidence sources to providers before analysis.
BoundResolver: Verify a custom evidence provider's declarations without executing an experiment.
Runnable: Report static refusals, data checks, and unknown feasibility requirements.
runnable: Inspect estimator feasibility without reading source data.
from_frame: Build an experiment and resolver from a unit-summary or unit-panel frame.
from_definitions: Build an experiment from warehouse definitions, or read its offline catalog.
from_unit_day_artifact: Build an experiment from a unit-day artifact.
from_switchback_frame: Build an experiment from a switchback panel.
from_moments: Build an experiment from retained moments.
render: Display qualified result cells for review.
