# Experiment dashboard theme explorations

Frozen synthetic checkout-redesign dashboard; no warehouse or Python kernel required.

```sh
python -m http.server 8765 --directory design/dashboard-themes
```

Open http://127.0.0.1:8765/dashboard-colour-comparison.html. Select a palette or **All eight themes**; Readout, Explore, and Report previews share the captured results. Full-size pages also include Health and metric inspection.

Current choices: original sage, Ink & Cobalt, Newsprint, Glacier, Midnight, Midnight · Daylight, Studio · Occupancy, and White & Orange. Earlier rounds preserve Terracotta, Violet Studio, and Carbon & Ice. Footer links navigate those rounds. Occupancy fonts load from Google Fonts, with local fallbacks.

Midnight · Daylight and Midnight are the selected production pair. This archive retains the alternatives and the original layouts independently of the production implementation. The newest round includes corrected active tabs, responsive metric inspection, complete comparison cards, and Occupancy print styling. Older rounds remain intentionally frozen.
