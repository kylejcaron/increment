# CUPAC

Demonstrates a frozen predictor trained on independent historical units, scores
experiment units before assignment, and passes that prediction as the CUPED
covariate. The notebook shows calibration, both estimate rows, a shifted-population
draw, and the refusal and bias risks of arm-dependent missing predictions.
