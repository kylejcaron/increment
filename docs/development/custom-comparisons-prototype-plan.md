**Goal:** Determine what the package must supply for a user-authored rank comparison to work across views. Report numerical agreement, slice counts and who owns arm/date alignment. Demonstrate a qualified custom method under multiplicity and repeated looks. This engineering study cannot decide whether analysts prefer an interface.

**Spec:** [User-authored comparisons](custom-comparisons-design.md). Its broad compatibility and performance gates apply to *promoting* an API, not promises from this prototype. This versioned plan sits beside the spec because `docs/superpowers/` is ignored in this repository.

**Architecture:** Two private Python experiments, one for authoring and one for inference, plus a script that compares them to actual built-in readouts and emits JSON. No public API or runtime changes. Both interfaces use the same frozen frame, not one verified production capture. The separate binary evidence example tests a sharp null; it is not a universal adapter for estimator p-values.

## Task 1: reproduce the candidate workflows and the inference evidence

These are the outputs of this task, not files assumed to exist at its base. Each executable prints JSON on stdout: `cells` keyed by view/date/treatment and measurements by interface; `looks` with ordered hypothesis, p-value, e-value and crossing histories plus exact null enumeration. Document the assumptions and refusal boundaries alongside the second executable.

- [ ] Using the named Mann–Whitney example on a sparse panel, verify exact unit membership and values against an independent reference, arm counts and means against built-in readouts, and rank effects against explicit pair counting. Change the view selection and check for missing, duplicated or misaligned results. Record which responsibilities belong to Increment and which remain the analyst's. To interpret the existing experiments: the two call-site sketches are research instruments; the pooled fit is a counterexample showing why pairwise dispatch would be unsafe. - [ ] Predeclare two binary-outcome hypotheses, fair independent assignment, a common outcome-independent finalization order and a sharp no-effect null per hypothesis. Exercise fixed-look correction and repeated-look inference with a predictable nonnegative betting process. Reject an incomplete hypothesis roster rather than shrinking the denominator. Reject an ordinary rank-test p-value as sequential evidence. Compare naive peeking against valid time-uniform monitoring by exact enumeration of equally likely assignments on a small outcome schedule; show a crossing, replay and invalid-input cases. Explain why this is not a rank test for a mean-lift null. Document primary sources and assumptions.
